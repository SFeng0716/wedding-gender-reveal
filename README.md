# Wedding Gender Reveal 💍

婚礼现场的宝宝性别揭晓小程序 —— 以井字棋（Tic-Tac-Toe）的方式，答对问题拆开信封，最后敲开中间的金色火漆，连成一线揭晓宝宝是男孩还是女孩。

## 玩法

1. **设置（共享屏幕之前）**：填写新郎 & 新娘名字（标题会变成 `新郎 & 新娘 Gender Reveal`），由新娘设置密码并秘密选择宝宝性别（之后查看 / 修改都需要密码；忘记密码只能清除重选），编辑 9 道问题。
2. **拆外围 8 封信**：点任意一封信 → 出现问题 → 答对才拆开。外围固定是 4 个蓝色（Boy）+ 4 个粉色（Girl）。
3. **金色火漆**：8 封信都拆开后才解锁。答对第 9 题 → 3、2、1 倒数 → 火漆裂开 → 连成一线 → 彩带 + “It's a Boy! / It's a Girl!”。

### 为什么拆完 8 封还猜不到？

外围的排列保证：
- 没有任何一条外围的行/列已经是同一个颜色；
- 恰好有一对 **蓝色** 和一对 **粉色** 隔着中间相对。

所以中间不管是什么颜色，都刚好连成 **一条** 线 —— 棋盘本身不泄露答案，只有金色火漆决定结果。（逻辑见 `js/board.js`，测试见 `tests/board.test.js`。）

## 使用

不需要安装任何东西，直接用浏览器打开 `index.html` 即可（建议 Chrome / Edge）。

**完整的使用手册在页面里**：设置页顶部的「📖 使用手册」，或揭晓页右下角的「?」。第一次打开时会自动显示。

- 右下角 ⛶ 或按 `F`：全屏，适合共享屏幕投影
- 右下角 ⚙：回到设置，进度会保留
- 设置页底部「全部重置，重新填写」：清除名字、性别和密码、题目和进度，回到一开始的样子
- 进度保存在浏览器本地（localStorage），不小心刷新也不会丢

### 题目类型

- **选择题**：填写正确答案 + 1–3 个错误选项，选项会随机排列；选错会划掉，直到选对为止
- **开放题**：错误选项留空，主持人点“揭晓答案”后判断来宾是否答对

## 设计：火漆信封

用 Anthropic 官方的 [`frontend-design`](https://github.com/anthropics/skills/tree/main/skills/frontend-design) skill 设计。

- **主题依据**：婚礼请柬套件。外围 8 格是象牙白棉纸信封，中间是印着两人名字首字的金色火漆，放在尤加利深绿的「桌面」上。
- **为什么用深色底**：婚宴厅灯光暗，投影仪会冲淡浅色。深绿底配浅色字和卡片，后排也看得清。
- **揭晓动作**：答对后信封盖掀开，蓝色或粉色卡片滑出；最后火漆裂成两半，信封打开，连成一条线。
- **色板**（`css/tokens.css`）：尤加利 `#1E3A33`、棉纸 `#F4EEE2`、香槟金 `#D4B47A`、火漆金 `#A5823F`、粉蓝 `#8FB5E6`、腮红粉 `#F0A3B8`
- **字体**：只用两套
  - **Parisienne**：名字、Boy / Girl、揭晓大字
  - **Noto Serif SC 思源宋体**（400 / 700 / 900）：其他所有文字
- `css/tokens.css` 放色板、字号、间距、圆角、阴影、层级；`css/style.css` 只引用 token。
