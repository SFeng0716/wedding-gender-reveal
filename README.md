# Wedding Gender Reveal 💍

婚礼现场的宝宝性别揭晓小程序 —— 以井字棋（Tic-Tac-Toe）的方式，答对问题拆开信封，最后拆开中间的金色信封，连成一线揭晓宝宝是男孩还是女孩。

## 玩法

1. **设置（共享屏幕之前）**：填写新郎 & 新娘名字（标题会变成 `新郎 & 新娘 Gender Reveal`），由新娘设置密码并秘密选择宝宝性别（之后查看 / 修改都需要密码；忘记密码只能清除重选），编辑 9 道问题。
2. **拆外围 8 封信**：点任意一封信 → 出现问题 → 答对后信封打开，滑出蓝色或粉色卡片。外围固定是 4 个蓝色（Boy）+ 4 个粉色（Girl）。
3. **金色信封**：8 封都拆开后才解锁。金色信封用珍珠白火漆封着，上面印着两人名字的首字。答对第 9 题 → 3、2、1 倒数 → 火漆裂开 → 连成一线 → 彩带 + “It's a Boy! / It's a Girl!”。

### 为什么拆完 8 封还猜不到？

外围的排列保证：
- 没有任何一条外围的行/列已经是同一个颜色；
- 恰好有一对 **蓝色** 和一对 **粉色** 隔着中间相对。

所以中间不管是什么颜色，都刚好连成 **一条** 线 —— 棋盘本身不泄露答案，只有金色信封决定结果。（逻辑见 `js/board.js`，测试见 `tests/board.test.js`。）

## 使用

不需要安装任何东西，直接用浏览器打开 `index.html` 即可（建议 Chrome / Edge）。

**完整的使用手册在页面里**：设置页顶部的「📖 使用手册」，或揭晓页右下角的「?」。第一次打开时会自动显示。

- 右下角 ⛶ 或按 `F`：全屏，适合共享屏幕投影
- 右下角 ⚙：回到设置，进度会保留
- 设置页底部「全部重置，重新填写」：清除名字、性别和密码、题目和进度，回到一开始的样子
- 进度保存在浏览器本地（localStorage），不小心刷新也不会丢

### 题目类型

- **选择题**：填写正确答案 + 1–3 个错误选项，选项会随机排列；选错会划掉，直到选对为止
- **开放题**：错误选项留空，主持人点“揭晓答案”后判断来宾是否答对

## 设计系统

- `css/tokens.css`：设计 token（金 / 蓝 / 粉 / 暖中性 50–900 色阶、语义色、1.25 大三度字号、8pt 间距、圆角、阴影、动效、z-index），结构参考 `ui-design-system` skill
- `css/style.css`：组件样式，只引用 token
- 字体（Google Fonts）：
  - **Pinyon Script**：名字、大标题
  - **Cinzel**：英文大写标签、按钮
  - **Noto Serif SC 思源宋体**（500 / 700 / 900）：中文标题、题目、正文，粗体保证投影清楚
  - **Ma Shan Zheng 马善政**：揭晓大字
