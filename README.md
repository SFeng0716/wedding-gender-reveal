# Wedding Gender Reveal 💍

婚礼现场的宝宝性别揭晓小程序 —— 以井字棋（Tic-Tac-Toe）的方式，答对问题翻开格子，最后翻开中间的金色格子，连成一线揭晓宝宝是男孩还是女孩。

## 玩法

1. **设置（共享屏幕之前）**：填写新郎 & 新娘名字（标题会变成 `新郎 & 新娘 Gender Reveal`），由新娘设置密码并秘密选择宝宝性别（之后查看 / 修改都需要密码；忘记密码只能清除重选），编辑 9 道问题。
2. **翻外围 8 格**：点任意格子 → 出现问题 → 答对才翻开。外围固定是 4 个蓝色（Boy）+ 4 个粉色（Girl）。
3. **金色格子**：8 格都翻开后才解锁。答对第 9 题 → 3、2、1 倒数 → 翻开 → 连成一线 → 彩带 + “It's a Boy! / It's a Girl!”。

### 为什么翻完 8 格还猜不到？

外围的排列保证：
- 没有任何一条外围的行/列已经是同一个颜色；
- 恰好有一对 **蓝色** 和一对 **粉色** 隔着中间相对。

所以中间不管翻出什么颜色，都刚好连成 **一条** 线 —— 棋盘本身不泄露答案，只有金色格子决定结果。（逻辑见 `js/board.js`，测试见 `tests/board.test.js`。）

## 使用

不需要安装任何东西，直接用浏览器打开 `index.html` 即可（建议 Chrome / Edge）。

- 右下角 ⛶ 或按 `F`：全屏，适合共享屏幕投影
- 右下角 ⚙：回到设置（会提醒先确认来宾看不到屏幕），翻牌进度会保留
- 进度保存在浏览器本地（localStorage），不小心刷新也不会丢

### 题目类型

- **选择题**：填写正确答案 + 1–3 个错误选项，选项会随机排列；选错会划掉，直到选对为止
- **开放题**：错误选项留空，主持人点“揭晓答案”后判断来宾是否答对
